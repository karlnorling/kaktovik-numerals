# Kaktovik Numerals

Stories for [`@kaktovik-numerals/core`](https://www.npmjs.com/package/@kaktovik-numerals/core), which renders any number as [Kaktovik numerals](https://en.wikipedia.org/wiki/Kaktovik_numerals) in SVG.

- **Number Builder**: type any number in the `value` control and adjust every `toSvg` option.
- **Digits**: every digit from 0 to 19.

Each digit is up to three fives across the top and up to four units below; the fives are the units turned a quarter turn. Zero is crossed arms. Places count in twenties, a dot starts the fraction, and negatives get a minus sign.

For downloads and shareable links, use the [playground](../playground/) in the docs.
